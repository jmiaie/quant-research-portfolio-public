# Validation Framework

[Back to main README](../../README.md)

This portfolio uses a staged validation workflow so that exploratory research, reproduced findings, and stronger evidence are clearly distinguished.

## Validation Stages

1. **Exploratory** — ideas, diagnostics, and prototypes that are not yet relied on for performance claims.
2. **Replicated** — project-reported outputs reproduced from a clean environment with documented data and assumptions.
3. **Benchmarked** — compared against relevant baselines, costs, and alternative specifications.
4. **Stress Tested** — reviewed under sensitivity analysis, uncertainty estimation, and failure-case analysis.

## Validation Deliverables

- Research question and economic rationale
- Data description and cleaning notes
- Experimental design and time splits
- Benchmark selection and justification
- Summary tables and figures tied to reproducible code paths
- Explicit list of unresolved risks, caveats, and next tests
